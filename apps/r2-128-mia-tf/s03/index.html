You can switch Hearth into full airplane mode from the side switch and the assistant, the calendar briefings and the automations all keep working. The only things that need a connection are extras you opt into, like weather or remote access.

Hearth ships with Hearth Core-7B, our distilled assistant model, plus Whisper-class transcription and an on-device embedding store for long-term memory. You can install any open-weight model up to 30 billion parameters (70 B on Hearth Pro) from the local model lab — quantised, verified and updated over the same encrypted channel as everything else.

Nowhere, by architecture. Hearth has no cloud account to sign in to, no telemetry pipeline and no ad IDs. Conversations, transcripts and sensor history live on the NVMe drive inside the box, encrypted with a key that is fused at manufacture. If you never want the box to phone out, the airplane-mode switch makes that physical, not a policy.

8 decibels at idle and 19 dB with every core lit — about the difference between a still room and a page turning. The aluminium body is the heat sink, so there is no fan, no rattle and nothing to dust out.

Hearth is a certified Matter device and a Thread border router, so bulbs, locks, valves and sensors join directly — no hub of their own. It speaks MQTT and has an open local REST API, so Home Assistant and custom automations treat it as a first-class brain, not a walled garden.

Memory and storage are soldered to the board, because a glued-shut box is a quieter box. What we can do: HearthOS keeps a per-device model cache, so when a better model lands you download it once and every Hearth in the house learns the same trick the same evening.
