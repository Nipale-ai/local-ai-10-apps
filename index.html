How it was measured

Same brief, same tools, same clock

  1. One brief per app. The model gets the prompt, a shell and a real browser. Nobody answers questions.
  2. 45 minutes, then stop. The model commits its work as it goes. The version that counts is its last commit that passes the checks.
  3. Automatic checks. A script opens every app and clicks through it: buttons, keyboard, totals, level changes, dark mode and more (12 to 18 checks per app).
  4. Everything runs at home. Models run on my own machines, the agent is OpenCode. No cloud model was used to build any app.

The benchmark runs, the checks and this page were set up by AI agents working for me. The apps on this page were written entirely by the local models named above.
